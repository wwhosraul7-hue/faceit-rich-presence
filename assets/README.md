# Assets

Imagini afișate pe Discord Rich Presence (hostuite aici, pe `raw.githubusercontent.com`,
pentru ca link-urile sa fie stabile si repo-ul sa fie sursa unica).

- **`levels/level_1.png` ... `level_10.png`** - iconițele reale de nivel FACEIT (cercul
  colorat cu numărul), extrase din fișierele jocului CS2 via
  [Sarrus1/FaceitLevels-for-kento-RankMe](https://github.com/Sarrus1/FaceitLevels-for-kento-RankMe).
- **`faceit-logo.png`** - semnul FACEIT (săgeata portocalie), decupat pătrat din logo-ul
  oficial ([Wikimedia Commons](https://commons.wikimedia.org/wiki/File:FACEITLogo.png), CC BY 4.0).
  Decupat special pentru ca Discord afișează large image-ul într-un cadru pătrat - logo-ul
  original e un banner lat și apărea tăiat/nerecunoscut.

Folosite de `src/app-config.js` (`levelIconUrl()`, `faceitLogoUrl()`).
